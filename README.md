# Motion Graphics Backend

Autonomous Motion Graphics Platform - Core API & Backend Server.

## 🚀 Tech Stack
- **Runtime**: Node.js (ES Modules)
- **Framework**: Express.js
- **Language**: TypeScript
- **Auth & Services**: Firebase Admin, Google OAuth
- **Cache / Queue**: Redis

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env` and fill in the required credentials:
```bash
cp .env.example .env
```

### 3. Start Development Server
```bash
npm run dev
```
Server runs by default on `http://localhost:3001`.
